# 공급 방식·위치 순환·공급 대기 통계
- 공급 방식: AGV_Groups "공급 방식" 열(Call / Cycle). Cycle = 호출 없이 상차↔하차 반복, 대기 CP 없음, 대수마다 모델 따로 빌드
- 위치 목록: `L001,L003`, `L001-L010` 범위. 상차는 차례로 순환, 하차는 공정별 자재 `M001@U002`(공정마다 재고·호출 따로)
- 언로딩 기준: 버퍼 있으면 버퍼에서, 없으면 하차 CP에서 기준 이하까지 대기 후 하차
- 공급 대기 수량·순환 교체 시간: 평균·최대, 재고+대기 합계, 대수별 표. 작업 화면·결론 탭·보고서
- 순환 권장 대수: 뒤차 대기율 95% 이상 최소 대수. 자재 품절 원인에 대수 부족·순환 차례 대기 추가
- 교통 CP: 기본 CAP INF, CAP 1 교통 CP는 `AGV_CP_TRAFFIC_CAP1` 레이어(보라)로 구분
