# 도면 경량화 재설계
- `AGVLITE`: 창 없이 바로 생성, 단계 0~4 자동 선택(목표 5 MB)
- 3D 블록 평면 투영: 기울어진 블록·솔리드·서피스·메시 모서리 포함
- 중복·겹침 선, 작은 요소 제거, 끊어진 선 잇기
- 빽빽한 덩어리(설비) 외곽선 치환, 벽·기둥·통로는 선 유지
- 큰 도면 읽기 진행 표시, Esc 취소, 원본 도면 변경 없음
- `AGVLITEX`(팔레트 "경량화 조정"): 단계 고정, 레이어 제외, 외곽선 끄기
- 임시 측정 명령 `AGVLITESTAT`: 도면 밀도·블록 표, Dense 기준은 측정 전 가늠값
