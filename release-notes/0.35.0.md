# 자재 품절 원인·미리 실행·영상 보정 재사용
- 자재 품절 원인: 구조적(소진 < 리드타임)·배차 대기·교통·교착·변동 판정, 결론 탭·작업 화면·보고서 시트
- 대수 탐색: 남는 슬롯에 다음 단계 미리 실행, 그룹 하나 남아도 동시 진행
- 영상: AutoView 보정값 저장·재사용, 매번 확인 안 함
- 결론 탭·보고서 500: 원인 분석 일부가 실패해도 화면 표시, 남은 오류는 내용을 화면에
- 교착 요약: 위치별 횟수·실행 수·첫 발생·차량, 원인 탭 지도로 이동, 보고서 "교착" 시트
- 최신 버전 확인: 단계별 진행(확인·받기 MB·준비), 뒤에서 실행
