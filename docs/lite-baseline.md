# AGVLITE 밀도 측정표

임시 측정. `AGVLITESTAT`(ZWCAD)로 저장된 도면마다 한 번 실행하고 한 줄씩 채운다. 측정은 Task 9 전에 아무 때나.
셀 = 1 m x 1 m, 값 = 셀 안의 선 길이(mm). 선 수 = 모델 공간에서 펼친 선분 수.

## 칸 채우는 법 (`lite\<이름>_lite.stat.tsv`)

| 칸 | stat.tsv |
|---|---|
| DWG MB | 도면 파일 크기 |
| 읽기 초 | `[시간]` 읽기 초 |
| 선 수 | `[도면]` 선분 수 |
| 잘림 | 명령줄에 "작업 한도로 일부만 읽음"이 나왔으면 예, 아니면 아니오 |
| 50% / 90% / 99% / 최대 | `[밀도 히스토그램]` 같은 이름 줄 |
| 0~1k ... 100k~ | `[밀도 히스토그램]` "셀 수 ..." 다섯 줄 |
| 상위 블록 1~5 | `[블록 상위 30]` 위 다섯 줄의 인스턴스 x 선 수 (마지막 열 `인스턴스×선`) |

## Dense 기준값 결정

(측정 후 채움)

- 가늠: 벽 두 줄 약 2,000 mm/m², 50 mm 간격 선 20개 약 20,000 mm/m².
- 도면마다 99% 와 "최대" 를 본다. Dense 는 "벽·기둥 같은 정상 선"의 99% 위, 설비 윤곽이 뭉친 셀의 아래로 잡는다.
- 정한 값은 `LiteLevels.Table`의 Dense 열 한 군데에 넣는다 (Task 6에서 만든다).
