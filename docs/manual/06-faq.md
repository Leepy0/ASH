# 6. 문제 해결

## 6.1 ZWCAD

| 메시지·증상 | 원인과 조치 |
|---|---|
| 리본에 `ASH` 탭이 없음 | 명령줄 `AGVRIBBON`. 팔레트는 `AGVPALETTE`. 그래도 없으면 ZWCAD를 완전히 끄고 다시 시작(설치 직후) |
| 도면을 먼저 저장하세요 | 설정·엑셀·모델 파일이 도면 폴더에 생기므로 저장한 도면이어야 한다 |
| 실행 중인 명령을 먼저 끝내세요. | 다른 명령이 입력을 기다리는 중. Esc로 끝내고 다시 누른다 |
| 도면 단위가 mm인데 Scale=1 입니다… | 설정 열기에서 배율을 `0.001`로 |
| 경로·CP가 엉뚱하게 크거나 작음 | 배율(Scale)이 도면 단위와 맞지 않음. mm 도면 = 0.001, m 도면 = 1 |
| 경로에서 너무 멉니다 (허용 0.05 m). | CP는 경로 위에만 놓인다. 경로 가까이 클릭하거나 좌표를 친다 |
| 이미 있는 이름입니다. | 상세 모드에서 쓴 이름이 이미 있다. 다른 이름 |
| 좌표를 쳤는데 엉뚱한 곳에 그려짐 | 동적 입력(F12)이 켜져 두 번째 점부터 상대 좌표로 들어갔다. F12로 끄고 다시 친다 |
| 빨간 원(끊긴 끝)이 사라지지 않음 | 끝이 0.3 m보다 떨어져 있다. "끝 연결" 또는 좌표 확인 |
| 주황 원(흐름 막힘) | 단방향 경로가 한 점으로 모이기만(나가기만) 한다. "방향 반전" |
| 그룹 보기에서 CP가 안 보임 | "숨김" 상태. "모두 표시" |
| 모델 생성 중단: 그룹 G1에 standby/buffer CP가 없습니다. | 그룹마다 대기 CP를 하나 이상 둔다. CP의 GROUP 철자 확인 |
| 서버 주소가 설정되지 않았습니다. AGVSERVER로 설정하세요 | `AGVSERVER`로 `http://<서버>:8082` |
| 서버에 연결하지 못했습니다 / 시간 초과 | 서버가 꺼졌거나 주소·방화벽 문제. 브라우저로 `http://<서버>:8082/healthz`가 `ok`인지 |
| 이 서버는 작업을 실행하지 않습니다 | 서버 설정 "작업 받기"가 꺼져 있다. 관리자에게 |
| 업데이트 중단(github.com에 접속할 수 없어…) | PC에서 github.com HTTPS가 막혔다. 프록시·방화벽 확인([server-install.md](../server-install.md) 6절) |

## 6.2 엑셀

| 메시지·증상 | 원인과 조치 |
|---|---|
| 빨간·주황 칸 | ASH 검증 표시. 칸 메모(`ASH 검증(오류): …`)를 읽고 고친 뒤 다시 "모델 생성" |
| Excel 읽기 오류: 시트!행 … | 그 칸의 숫자 형식·빈칸. 메시지가 시트·행·열을 알려 준다 |
| 예시 자재 `M001`이 모델에 들어감 | 회색 기울임 예시 행을 지우지 않았다 |
| 드롭다운에 CP가 안 나옴 | 그 열의 TYPE CP가 도면에 없거나 양식이 오래됐다. `AGVEXCEL` → `U` |
| 암호화된 파일 | Excel을 통해 읽고 고친다. Excel에서 셀 편집 중이면 실패 — 편집을 끝내고 다시 |
| 엑셀과 도면이 맞는지 모르겠음 | "엑셀·도면 비교"(`AGVEXCELDIFF`) |

## 6.3 서버·결과

| 메시지·증상 | 원인과 조치 |
|---|---|
| 작업이 계속 "대기" | 앞 작업이 도는 중. 홈 "진행"의 대기 건수와 예상 시작 시각 |
| 모델 재생성 필요 | 엑셀의 그룹·타입·자재·루트 같은 모델에 굳는 값을 바꿨다. "모델 생성" 후 다시 보내기 |
| 결과에 "-"만 나오는 칸(가동률 정의, 시간 내역) | 그 기능 전 버전으로 만든 모델. 지금 버전으로 "모델 생성"을 다시 하고 보낸다 |
| 주황 "경고: 가동률 초과" | 실패가 아니다. 대수는 상한을 넘지 않는 값으로 찾는다 |
| 빨강 실패 | 자재 품절, 생산 미달, 교착, 결과 없음. 원인 탭과 작업 화면 로그 |
| 최대 대수에서도 실패 | MaxCount를 늘리거나 T/T·경로를 다시 본다. 원인 탭의 "시간 손실", "block 점유" |
| 대수 다시 돌리기 403 / 410 | 403: 보낸 PC나 관리자가 아니다. 410: 보낸 파일이 없다(보관 기간) |
| 영상이 실패 | 서버의 AutoView·ffmpeg 문제. 관리자가 [server-install.md](../server-install.md) "영상 촬영"의 진단을 본다 |
| 시스템 알림이 안 뜸 | http 주소라 정상. 화면 안 알림만 된다 |

## 6.4 AutoMod 체험판

| 증상 | 조치 |
|---|---|
| 빌드 중 "Entity Limit Status" 창 | 체험판은 엔티티 200개까지. 따라하기 예제는 이 안에서 빌드된다(이 창이 떴다 닫히고 빌드 성공) |
| 큰 도면이 빌드 실패 | 경로·CP·block·컨베이어 구간·3D가 200개를 넘는다. 서버(정식판)로 보낸다 |
| `ash-run`이 Authorization 창에서 멈춤 | 체험판은 `--dialog-button "Student Version"`을 준다. 서버는 설정 "대화상자 버튼"(`Jobs:DialogButton`) |

## 6.5 어디에 무엇이 있나

| 파일 | 위치 |
|---|---|
| 도면 설정 | `<도면 폴더>\ash.settings.tsv` |
| 입력 | `<도면 폴더>\input.xlsx`, 백업 `input.bak.<시각>.xlsx`, 스냅샷 `input.cells.tsv` |
| 모델 | `<도면 폴더>\model.arc\` (이름은 설정 "모델 이름") |
| 마지막 보낸 작업 | `<도면 폴더>\ash.job.txt` |
| 서버 주소·레이어 색(PC별) | `%APPDATA%\ASH\ash.user.tsv` (PC 공용 `%ProgramData%\ASH\ash.machine.tsv`) |
| 플러그인 로그 | `%APPDATA%\ASH\plugin.log` |
| 설치 로그 | `%TEMP%\ASH-install.log` |
