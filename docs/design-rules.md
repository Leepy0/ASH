# ASH 웹 화면 규칙 (HIG 기반, 2026-10-24)

시안: `docs/ux-mockups/` — `hig-home-lanes-1080p.png`(홈), `hig-analysis-1080p.png`(분석), `hig-video.png`(영상 만들기).

## 사용자와 흐름

주 사용자는 시뮬레이션 작업자다. 목적: **내 작업 상태 → 문제 확인 → 결론 확인 → 영상 제작 → 보고서**.
서버 상태·설정은 작업자 화면에 두지 않는다. "관리"(사이드바 맨 아래)로만 간다.

## 배치

- PC 전용(1440×900 ~ 1920×1080). 화면은 **창 높이를 채운다**: 목록·지도처럼 늘어나도 되는 칸이 남는 높이를 쓰고, 넘치면 그 칸 안에서 스크롤. 숫자 카드를 억지로 늘리지 않는다.
- 왼쪽 사이드바: 평소 60px 아이콘만, 마우스를 올리면 220px로 펼쳐 이름이 보인다(본문을 밀지 않고 위에 겹침). 항목: 홈 `/`, 분석 `/analyses`, 영상 `/films`, 보관함 `/files`, (맨 아래) 관리 `/admin/settings`.
- 홈은 단계별 세로 구획(lane): 진행 | 결론 확인 | 영상 | 보고서. 구획마다 색 띠·개수.
- 분석은 목록(왼쪽 270px) + 상세. 상세 첫 화면은 결론: 핵심 숫자 4개 → 그룹별 권장 대수(문제 먼저) + 안별 결론 | 병목 지도(남는 높이 전부).

## 글자 위계 (중요도 = 크기 + 색)

| 등급 | 쓰임 | 클래스 | 크기·굵기·색 |
|---|---|---|---|
| T1 | 핵심 숫자(권장 대수, 진행률) | `.t1` | 44~56px, 700, 단계 색 또는 `--blue` |
| T2 | 이름(분석·작업) | `.t2` | 18~20px, 700, `--ink` |
| T3 | 설명·지표 이름 | `.t3` | 14px, 400, `--sub2` |
| T4 | 시각·단위·보조 | `.t4` | 13px, `--sub2` |

- 최소 글자 13px. 카드 안 글자는 **가운데 정렬**. 표·목록 줄은 왼쪽 정렬, 숫자는 오른쪽.
- 설명 문장은 최소로. 긴 도움말은 `title` 속성이나 접힌 `<details>`로. 기본값·설정 키 같은 개발 정보는 화면에 쓰지 않는다(관리 화면 제외).

## 색 (상태는 색 + 기호 함께)

| 의미 | 토큰 | 기호 |
|---|---|---|
| 진행·주 동작 | `--blue` #007aff | ▶ |
| 결론 확인 | `--indigo` #5856d6 | ● |
| 영상 | `--orange` #c45500 | ◐ |
| 보고서·정상 | `--green` #248a3d | ✓ |
| 문제(상한 초과, 결품, 실패) | `--red` #d70015 | ▲ ⚠ |
| 과소(10% 미만 등 여유 과다) | `--gray` #8e8e93 | ▼ |

- 그룹 가동률: 상한(UtilMax) 초과 = 빨강 ▲, 10% 미만 = 회색 ▼, 그 밖 파랑. 막대에 상한 위치 세로선.
- 한 카드에 **채운 파란 버튼은 하나**(다음에 할 일). 나머지는 회색 버튼(`.btn`).

## 접근성

- 대비: 글자 4.5:1 이상, UI 경계 3:1 이상. 선택 상태는 색 + ✓/굵기.
- 버튼·줄 높이 최소 34px(목록 줄 44px), 키보드 초점 링 `:focus-visible` 3px.
- 아이콘만 있는 버튼은 `aria-label`. 경고는 `role="alert"`.

## 코드 규칙

- 공용 CSS·셸은 `JobPages.Css` / `JobPages.Page(title, body, script, nav)`에만. 화면 전용 CSS는 그 화면의 `<style>` 블록에(다른 화면과 충돌 방지).
- 공용 부품 클래스(아래)를 먼저 쓴다: `.box` `.card` `.kpis` `.kpi` `.lane` `.lane-h` `.lane-b` `.segc` `.btn` `.btn.pri` `.tag` `.tag.{blue,indigo,orange,green,red,gray}` `.warn` `.grp` `.pv` `.row` `.t1~.t4` `.fill`(높이 채우는 세로 flex).
- 기존 기능·경로·폼 이름·API는 바꾸지 않는다. 테스트가 확인하는 문구가 바뀌면 테스트도 같이 고친다.
