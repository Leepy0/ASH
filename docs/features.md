# ASH 기능 목록 (0.25.0)

지금 되는 기능을 사용 단계별로 적는다. 사용법은 [README](../README.md), 서버 운영은 [server-install.md](server-install.md), 입력 양식은 [input-template.md](input-template.md).

## 1. 도면 · 입력 (ZWCAD)

- `AGVINIT`으로 레이어·블록을 만들고, `AGVRIBBON`·`AGVPALETTE`로 리본 탭과 팔레트를 연다.
- `AGVPATH`로 경로를 그린다. 종류는 단방향 · 양방향 · 지선 · 크랩이고 `AGVPTYPE`으로 바꾼다.
- `AGVSPLIT` `AGVREVERSE` `AGVFILLET` `AGVOFFSET` `AGVARRAY` `AGVJOIN`으로 경로를 고친다.
- `AGVCONVERT`로 일반 선·폴리선을 경로로 바꾸고 교차를 나눈다.
- `AGVCP`로 CP를 놓는다. TYPE은 traffic · load · unload · rtnload · rtnunload · standby · buffer · finish다.
- `AGVTRAFFIC` `AGVBLOCKAUTO` `AGVBLOCKNUM`으로 block을 만들고 번호를 붙인다.
- `AGVCHECK`로 도면을 검사하고 문제를 표로 보여 준다. `AGVFIND`로 객체를 찾아 이동한다.
- `AGVEXPORT`로 `agv.asy`와 `traffic.tsv`를 내보낸다.
- `AGVEXCEL`로 입력 양식(`input.xlsx`)을 도면의 CP로 채워 만들고, 새로 생긴 것만 갱신한다.
- 서버의 AGV 타입 목록과 에셋 이름이 `AGV_Types`에 채워지고 드롭다운이 된다.
- 사내 문서 암호화로 직접 못 읽는 `input.xlsx`는 Excel로 읽는다.

## 2. 모델 생성 (ZWCAD, AutoMod)

- `AGVMODEL`이 입력을 검사하고 `<모델>.arc`를 만든다(빌드는 하지 않는다, 0.26.9). 이어서 서버로 보낼지 묻는다. 이 PC의 AutoMod로 보려면 `AGVRUN`(필요하면 그때 빌드).
- `AGVRUN`으로 만든 모델을 AutoMod 창에서 연다.
- 차량 형상 4종(Standard · Conveyor · Ant · Magnet)과 적재물 3종(Box · Pallet · Trolley)을 그린다.
- 서버 에셋(STL·OBJ에서 변환한 `.cel`)을 차량 그림으로 쓴다.
- 고장(MTBF·MTTR), 공차 속도, 용량, 가감속, 감지 거리가 모델에 들어간다.
- 호출 · 탑승 · 이동 · 회수 · 대기 CP 복귀의 공급 로직을 만든다. 버퍼 대기 허용(`BufferWaitSec`)을 둘 수 있다.
- 가동률은 대기 CP에서 탄 순간부터 FinishCP 도착까지로 센다. 시간 내역(주행 · 상하차 · 버퍼 대기 · 고장 · 유휴)을 기록한다.
- block은 채운 상자가 아니라 외곽선으로 그린다.
- `input.sig`에 입력 지문을 남겨, 입력이 달라지면 모델 재생성이 필요하다고 알린다.

### 3D 그림(에셋)

- `AGV3D`(팔레트 3D 탭)로 로봇 대·중·소, 랙, 설비, 기둥, 충전기, 작업대, 출입문, 바닥 표시 블록(`ASH_3D_*`)을 놓는다. 크기는 블록 X/Y 배율(1 = 기본 크기), 방향은 회전이다.
- `AGV_3D_WALL` 레이어의 선·폴리선은 벽(두께 0.2 m 또는 폴리선 폭, 높이 3 m), `AGV_3D_FENCE`는 안전 펜스(높이 2 m, 기둥 2 m 간격)가 된다. 호는 10° 이하 조각으로 나눈다.
- 모델 생성이 `assets.tsv`와 정적 시스템 `ash_3d.asy`를 `.arc`에 넣는다. AutoMod 3D 창과 영상에 나오고 시뮬레이션 결과에는 영향이 없다. 영상의 도면 배경에서는 `AGV_3D*` 레이어의 2D 선을 뺀다.
- 그림 예: [ash_model_assets.jpg](superpowers/specs/2026-10-26-3d-assets/ash_model_assets.jpg)

## 3. 서버 실행 · 대수 탐색

- `AGVSEND`로 모델을 서버에 올린다. 분석 · 안 · 메모 · 태그(법인 · 제품군 · 라인)를 고르고 도면(DWG)을 같이 보낸다.
- 서버가 작업 대기열대로 빌드하고 그룹별 최소 대수를 탐색한다(동시 실행 수 설정).
- 판정은 공정 정지 · 안전재고 · 가동률 상한 · 생산 달성 · 교착이다. 가동률 상한 초과는 실패가 아닌 경고다.
- `ash-run`으로 내 PC에서 같은 탐색을 돌리고 `AGVRESULTUP`으로 결과를 올린다.
- 결론 화면에서 그룹 대수를 바꿔 확인 실행만 다시 돌린다(같은 안의 새 버전).
- 끝난 작업의 실행 원본은 설정한 일수 뒤 `runs.zip`으로 압축해 보관한다.
- 플러그인은 새 버전을 알리고 `AGVUPDATE`로 설치 파일을 받는다(서버 주소는 `AGVSERVER`). `ash-run`과 서버는 GitHub 릴리스로 스스로 교체한다.

## 4. 결론 확인 (웹)

- 홈은 네 구획 진행 | 결론 확인 | 영상 | 보고서이고 내 것 | 전체를 바꿔 본다.
- 분석 결론은 핵심 숫자 · 그룹별 권장 대수(문제 먼저) · 병목 지도 · 안별 결론이다.
- 병목 지도는 block 평균 대기를 색으로 보이고 상위 5개를 번호로 짚는다.
- 병목 지도의 "통행량" 보기는 경로마다 지나간 차량 수(AutoMod 보고서의 Guide Path Total, 확인 실행 평균)로 경로를 색칠·굵게 그려 가장 붐비는 곳을 보이고 상위 5개 경로를 짚는다(0.26.8).
- 상세 탭의 실행 목록은 권장 대수 그대로 판정을 통과한 실행에 "적정"을 붙이고, 그 시드들의 모델 zip 받기 버튼을 표 위에 모은다(0.26.8).
- 입력의 Materials.Flow = Output은 빈 용기 공급 + 풀 용기 반출(교환)이다. 계산은 공급과 같고 그림이 뒤집히며 결과에 "(반출)"이 붙는다(0.26.8).
- 안과 버전을 비교하고 안마다 선정 버전을 고른다.
- 작업 상세에 시간 내역 막대 · 차량별 표 · 자재별 공급 빈도 · 리드 타임 · 재고 · 대수-가동률 곡선 · 영향표가 있다.
- 입력 · 추적 탭에 올린 파일과 SHA-256이, 다운로드 탭에 `summary.tsv` · `runs.zip` · 로그 · Excel 보고서가 있다.
- 보관함(`/files`)에서 보낸 파일을 찾아 `continue.zip`으로 이어서 작업한다.
- 내 작업 · 영상이 끝나거나 실패하면 알린다(http는 화면 안 토스트와 탭 제목 "(n)", https는 시스템 알림).

## 5. 영상 (웹, AutoView)

- 영상 만들기에서 도면 위에 구역을 그려 컷을 만든다. 종류는 구역 고정 · A → B 이동 · 전체다.
- 시뮬레이션 길이 · 배속 · 영상 길이가 서로 연동되고 배속은 고정할 수 있다.
- 시점 조정으로 방향(Z) · 기울기(X) · 회전(Y) · 원근을 정하고, 시점을 복사해 붙이거나 모든 컷에 적용한다.
- 컷마다 차량 대수를 결론 대수에서 가감할 수 있다.
- 장면 후보(재고 소진 · 지연 급증 · 병목 · 전체)를 눌러 컷으로 넣는다.
- 병목 지도의 "＋ 컷"이 그 block을 찍는 컷을 채워 연다.
- 컷 미리보기가 AutoView로 첫 장면 1장을 그린다.
- 컷마다 AutoView로 찍고 ffmpeg로 자막을 넣어 이어 붙인다(MP4, 컷 파일은 `all.zip`).
- 영상 목록(`/films`)과 영상별 진행 · 컷별 상태 · `film.log`를 본다.

## 6. 보고서 (웹)

- 인쇄용 보고서 화면을 "PDF로 저장"한다(A4 가로, 표지 · 그룹 · 자재 · 병목 지도 · 영상).
- PPT를 받는다. 결론 제목, 파워포인트 차트(데이터 편집 가능), 병목 지도, 영상 썸네일 링크, 상세 표는 부록이다.
- Excel 보고서(요약 · 대수별 가동률 · 실행 목록 · 영향표 · block · 입력 · 차량 · 자재)를 받는다.

## 7. 관리 (웹, 서버)

- 관리자 암호로 설정을 웹에서 바꾼다(스위치 · 단위, 저장 때 검사, 이전 파일 `.bak`). 경로는 서버 PC 폴더를 "찾아보기"로 고른다.
- 서비스 다시 시작, 작업 대기열, 실행 중 작업 취소(보낸 PC나 관리자).
- AGV 타입 · 투자비 단가 · 에셋을 관리하고, 타입 · 단가는 엑셀 양식을 받아 붙여넣어 한꺼번에 넣는다.
- GitHub 릴리스를 가져오고 서버를 스스로 업데이트하며 실패하면 되돌린다. 수동 업로드도 된다.
- 분석 삭제(관리자 암호와 분석 이름 확인).

## 알아 둘 점

- 가동률 정의(0.24.0)와 시간 내역(0.25.0) 같은 새 출력은 모델 로직이 기록한다. 그 버전 이후 `AGVMODEL`로 다시 만든 모델에서만 나오고, 옛 모델은 "-"로 보인다. 입력이 그대로면 `ash-run`이 알려 주지 않으니 직접 다시 만들고 `AGVSEND`한다.
- http 인트라넷 주소에서는 브라우저가 시스템 알림을 막는다. 화면 안 알림만 된다. https(PC가 신뢰하는 인증서) 또는 Chrome/Edge 기업 정책이 필요하다. 모든 탭을 닫은 뒤의 푸시는 지원하지 않는다.
- AutoView는 12.6에서 확인했다. 12.4(AVI 출력)는 개발 PC에서 확인하지 못했다.
- 영상과 컷 미리보기는 작업과 같은 일꾼 하나를 쓰므로 큰 작업이 도는 동안은 그 뒤로 밀린다.
- 지원 ZWCAD는 2026뿐이다.
